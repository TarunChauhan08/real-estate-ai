# AI Real Estate Sales Employee

A multi-tenant SaaS platform that gives Indian real estate brokers, agencies, builders and developers an AI sales employee — one that talks to buyers in Hindi, English and Hinglish, qualifies leads, recommends verified inventory and books site visits.

> **Never miss a property enquiry. Turn more enquiries into qualified buyers and site visits.**

This repository is being built in phases. Phase 1 (foundation: auth, tenants, memberships, RBAC, onboarding, team management, dashboard shell, audit logs) lands through the `feature/*` branches — see each branch for its scope.

Full setup and development instructions are added in `feature/07-tests-docs`.
